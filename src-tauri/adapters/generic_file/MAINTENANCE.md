# 通用文件引导映射维护

## 版本与模板兼容

- 修改 CSV、JSON 解析、字段转换或来源字典模板行为时，递增 `manifest.json` 的 `version`，并在 `changes` 增加当前版本说明。
- 仅在旧模板仍可安全复用时保留 `templateCompatibleFromVersion`；不兼容变更应将它提高到新的最低兼容版本。
- 每次恢复模板仍会对当前文件的真实字段重新校验，来自未来版本的模板不能降级套用。

## 项目差异处理

1. 文件列名或取值差异优先通过引导映射和来源模板解决，不在适配器中写入项目路径或客户信息。
2. 如现场自动识别流程提供支持包，运行 `npm run adapter:support -- --file <支持包.json>` 检查完整性、脱敏状态和结构变化。
3. 解析规则变更必须补充前端转换测试，确保预览与正式执行语义一致。

## 交付门禁

运行 `npm run adapter:verify`，确认清单、维护说明和适配器注册全部通过后再构建桌面程序。
