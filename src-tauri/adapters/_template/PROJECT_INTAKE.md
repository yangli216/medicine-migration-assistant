# 三方 HIS 接入调查清单

本文件只记录表、字段、关系和业务口径。不得填写数据库地址、账号密码、患者信息、样例药品或业务数据；现场结构证据应来自应用导出的脱敏支持包。

## 1. 能力与版本

- [ ] HIS 产品、正式版本、项目补丁和支持任务已确认。
- [ ] 数据库家族与只读账号的可见对象范围已确认。
- [ ] 已明确自动适配、引导映射和暂不支持的边界。
- [ ] 动态 Schema/对象名和本批机构/库房过滤统一使用公共 SDK，不复制引号或转义逻辑。

## 2. 药品主数据

| 必须确认 | 证据要求 | 完成 |
| --- | --- | --- |
| 药品与商品/厂家关系 | 表名、关联字段和零或多商品的业务含义 | [ ] |
| 稳定来源键 | 整批非空、唯一、长期不复用；复合键顺序固定 | [ ] |
| 迁移范围 | 全部、机构配置、机构在用等范围的真实判定关系 | [ ] |
| 人可识别字段 | 名称、规格、剂型、最小单位、厂家和商品名来源 | [ ] |
| 字典语义 | 编码含义来源、项目覆盖规则和读取失败处理 | [ ] |
| 可选依赖 | 缺失时安全留空、降级或阻断的明确规则 | [ ] |

## 3. 机构库存（如支持）

| 必须确认 | 证据要求 | 完成 |
| --- | --- | --- |
| 机构与库房目录 | 稳定键、类型、启停状态及归属关系 | [ ] |
| 轻量范围读取 | 范围选择前不枚举全量库存明细 | [ ] |
| 选择后下推过滤 | 未选择的机构和库房不进入来源 SQL | [ ] |
| 库存与商品稳定键 | 可解释且不因关联重复 | [ ] |
| 管理包装 | 单位、换算系数和结构化单包装证据 | [ ] |
| 数量与金额 | 单位、价格、金额及舍入规则 | [ ] |
| 批号与效期 | 物理类型、空值和字符日期格式 | [ ] |
| 首次盘点边界 | 写入、试迁移和撤销保持公共安全流程 | [ ] |

## 4. 可交付证据

- [ ] 每个任务都有通过及关键缺失/歧义夹具。
- [ ] v2 夹具只含表名、字段名、数据库物理类型和业务预期。
- [ ] 每个夹具绑定真实可执行 Rust 测试。
- [ ] `acceptance.json` 完整声明必需、条件、可选依赖和安全降级。
- [ ] `npm run adapter:verify`、Rust 全量测试和桌面构建均通过。
