# 通用数据库引导映射维护

## 版本与模板兼容

- 修改只读 SQL、字段转换或来源字典模板行为时，递增 `manifest.json` 的 `version`，并在 `changes` 增加当前版本说明。
- 仅在旧模板仍可安全复用时保留 `templateCompatibleFromVersion`；不兼容变更应将它提高到新的最低兼容版本。
- 每次恢复模板仍会对当前批次的真实字段重新校验，来自未来版本的模板不能降级套用。

## 项目差异处理

1. 优先让实施人员通过引导映射完成项目配置并导出来源模板，不为单个项目加入固定连接或 SQL。
2. 如现场自动识别流程提供支持包，运行 `npm run adapter:support -- --file <支持包.json>` 检查完整性、脱敏状态和结构变化。
3. 确认通用能力不足时，创建独立厂商适配器，而不是把厂商表名写入通用适配器。

## 交付门禁

运行 `npm run adapter:verify`，确认清单、维护说明和适配器注册全部通过后再构建桌面程序。

同一目标租户的重复项目可由应用推荐本机同结构模板。该路径只复用当前字段仍全部存在的映射和转换规则；不得复用旧查询、连接身份或来源字典，且必须在当前来源中重新核对后保存。

表/视图样例后的批量预检只允许探测前 10,001 行，并使用独立的 12 秒短超时。不得改回对整张老系统业务表执行无界 `COUNT(*)`，也不得沿用正式读取的长超时；小批返回准确数，大批按“至少 10,001 行”处理并要求稳定拆分，超时则无阻断降级。
